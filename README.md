# Data Exploration and Visualisation – Group Coursework

## Project Overview

This group coursework project is based on **IslandMart**, a fictional Mauritian retail chain operating across multiple districts and sales channels, including in-store, online, and delivery services.

The project focuses on the **Moka district** and the **Electronics product category**, analysing 24,000 transaction records to explore sales performance, customer behaviour, and operational efficiency.

## Objectives

* Perform data cleaning and auditing
* Conduct exploratory data analysis
* Analyse spatial and time-based patterns
* Examine sales and customer behaviour
* Evaluate operational performance
* Develop an interactive Power BI dashboard
* Identify key findings and provide recommendations

## Tools & Technologies

* **R**
* **R Markdown**
* **Power BI**
* Exploratory Data Analysis
* Data Visualisation
* Spatial Analysis
* Time-Series Analysis
